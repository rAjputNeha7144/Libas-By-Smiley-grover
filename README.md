Yes. Once you deploy your React/Vite website on Vercel, the Vercel URL is publicly accessible from any device that has an internet connection:

💻 Laptop/desktop
📱 Android/iPhone
📲 Tablet
🌐 Different browsers
📍 Someone in another city/country

For example, if Vercel gives you:

https://smiley-grover.vercel.app

you can send that link to the owner and she can open it on her phone.

One important distinction

The link works on every device, but your website's appearance needs to be responsive.

You've already been working on responsive CSS, so after deployment I recommend testing the Vercel link on:

Your laptop
Your phone
The owner's phone

Pay particular attention to the hero video, navbar/mobile menu, collection images, and footer.

Also, if you later change the website and push the changes to GitHub, Vercel can automatically update the same link. So you won't need to send a new URL every time.


# Smiley Grover – Ethnic Fashion Website

A modern, responsive clothing brand website designed and developed using React.js.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern fashion-focused UI
- Hero video section
- Collection showcase
- Featured products section
- Smooth section navigation
- Mobile navigation menu
- Instagram integration
- Responsive footer

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- React Icons
